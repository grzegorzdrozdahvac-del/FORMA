# Forma

Aplikacja do regeneracji i treningu oparta na HRV z opaski (WHOOP 4.0 przez HR Broadcast, Polar).

- `index.html` – aplikacja Forma 0.2
- `prototyp-0.1.html` – poprzednia wersja (prototyp) (działa w Chrome/Edge na komputerze i w Chrome na Androidzie, przez Web Bluetooth)
- `test-hrv.html` – strona testowa połączenia i HRV

Dane zapisują się tylko w przeglądarce użytkownika. Narzędzie testowe, nie jest wyrobem medycznym.
